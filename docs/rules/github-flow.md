# GitHub Flow

- Before starting each task, create a separate branch from the current default branch; do not work directly in 'master'/'main' or another shared branch.
- Name task branches using the type and concise transliterated feauture or fix name: `feat/<transliterated-name>` for new functionality and `fix/<transliterated-name>` for bug fixes.
- Use lowercase Latin characters, separate words with hypnens, and avoid spaces, punctuation, and Cyrillic characters and branch names.
