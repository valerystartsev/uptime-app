Нужно реализовать задачу

## [C] Context /Контекст
Мы хотим, чтобы пользователь мог загрузить свой аватар в профиль, и он бы у него отобразился.

## [O] Результат / Цель - что должно быть
Пользователь заходит в редактирование профиль, нажимает "загрузить аватар", выбирает изображение подходящего формата jpeg или png. После этого нажимает "выбрать". У него появляется новый аватар и кнопка "сохранить", которая обновляет этот аватар. При нажатии "Сохранить" в профиле пользователь теперь отображается новый аватар, и в панели верхней тоже отображается обновленный аватар.

## [S] Границы
Все загружаемые файлы хранятся локально под общим корневым каталогом, исключённым из Git. Разные виды файлов размещаются в отдельных подкаталогах. Аватар — один из таких видов; для него действуют ограничения на формат и размер, и его нужно отдавать frontend для отображения в профиле.

## [T] Проверка/Test - когда готово
Тест загрузки аватара и новый API для загрузки изображения работает.
